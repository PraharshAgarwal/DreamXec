Onboarding Blueprint

Verification & RBAC Roles

Interactive workflow blueprints showing how users register globally and scope memberships across tenants using the UserOrganization collection. Select a role profile tab to view verification gates.

Student Researcher Onboarding Details

Step 1: Domain Check

Creates global user. Validates academic email domain (.edu).

User.role = "USER"

Step 2: ID Upload

Uploads Student ID card / Enrollment scanning documents.

StudentVerification = PENDING

Step 3: Approval

Registrar Admin audits scanned credentials manually.

User.studentVerified = true

Step 4: Activation

Creates university linkage. Unlocks shared lab book tools.

UserOrg.role = "RESEARCHER"

Professor / PI Onboarding Details

Step 1: Faculty Input

Faculty enters official ORCID iD for publication indexing audits.

User.orcid = String

Step 2: Rank Scan

Uploads official employment contract scan for university verification.

UserOrg.verified = false

Step 3: Admin Review

University registrar verifies appointment scan details.

AuditLog.action = FACULTY_VERIFY

Step 4: Active PI

Unlocks stage-gate reviews, lab booking, and grant oversight.

UserOrg.role = "PROFESSOR"

Incubator Manager Onboarding Details

Step 1: Direct Invite

Invited directly via email invitation token sent by university admin.

User.role = "USER"

Step 2: Acceptance

Accepts secure token, configures password, and joins university space.

UserOrg.role = "INCUBATOR_MANAGER"

Step 3: Board Active

Unlocks evaluation scoring boards (Novelty & Feasibility gates).

UserOrg.verified = true

Corporate Sponsor / Donor Onboarding Details

Step 1: Sponsor Signup

Sponsor registers with corporate email domain password.

User.role = "DONOR"

Step 2: Biz Registry

Inputs legal GSTIN/EIN registrations and banking profiles.

Donor.verified = false

Step 3: Compliance

Platform admin validates standing against public registry indexes.

Donor.verified = true

Step 4: Grant Posting

Unlocks grant creation, milestone audit review panels.

prisma.grant.create()

Compliance Officer Onboarding Details

Step 1: Secure Invite

Invited via direct cryptographic secure token sent by Org Admin.

User.accountStatus = ACTIVE

Step 2: Board Setup

Joins university workspace as verified compliance officer.

UserOrg.role = "COMPLIANCE_OFFICER"

Step 3: IRB Active

Unlocks review panels for ethical clearance protocol auditing.

prisma.stageGateReview.create()

Organization Admin Onboarding Details

Step 1: Org Setup

Registers legal university credentials and domain mappings.

Organization.verified = false

Step 2: Platform Clearance

DreamXec Super-Admin validates institutional legitimacy.

Organization.verified = true

Step 3: Tenant Control

Unlocks domain whitelist setup, department creation, lab config.

UserOrg.role = "ORG_ADMIN"
