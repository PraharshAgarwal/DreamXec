🕸️ System Overview & Architecture Map

Dreamxec is a comprehensive, multi-tenant University and Corporate Research ERP. It manages the entire research and innovation lifecycle: from user authentication, academic organizational hierarchies, ideation stages, project management, shared laboratory bookings, milestone-based grant funding, up to patent filings and royalty splits.
